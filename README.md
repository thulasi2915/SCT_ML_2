# SCT_ML_2

## Task: K-Means Clustering on Mall Customer Dataset

### 📘 Description
This project implements a **K-Means clustering algorithm** to group retail store customers based on their purchase patterns using the Mall Customer Dataset.

### 🧩 Objective
To identify different types of customer groups (e.g., high spenders, budget shoppers, etc.) to support marketing and business strategies.

### 🧠 Algorithm Used
- K-Means Clustering

### 🧰 Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

### 📊 Steps Involved
1. Importing libraries and dataset
2. Data preprocessing
3. Selecting relevant features (`Annual Income`, `Spending Score`)
4. Applying the **Elbow Method** to find optimal clusters
5. Implementing **K-Means clustering**
6. Visualizing the clusters

### 🖼️ Output
- Cluster visualization (scatter plot of customers)
- Centroid locations
- Customer segmentation insights

### 📁 Dataset
**Mall_Customers.csv**
